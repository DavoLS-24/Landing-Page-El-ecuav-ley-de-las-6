# Ecuavóley en La Esperanza

Landing page sobre la práctica de ecuavóley en el coliseo parroquial de La Esperanza (Quevedo, Ecuador), desarrollada con HTML y CSS para la materia **Desarrollo de Aplicaciones Web y Móviles** de ESPOL.

🔗 **Sitio en línea:** (https://davols-24.github.io/Landing-Page-El-ecuav-ley-de-las-6/)

## Sobre el proyecto

Cada tarde y noche, jóvenes de la comunidad se reúnen en el coliseo para jugar ecuavóley, formar equipos y organizar minitorneos. A partir de entrevistas y observación directa, este sitio presenta quiénes participan, cómo se organizan, sus motivaciones, el impacto social de la actividad y las propuestas de mejora. La información se usa solo con fines académicos y sin datos personales.
